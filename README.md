# Employee-Performance-Analysis
This dashboard provides a comprehensive analysis of employee performance based on sales activities recorded across various locations and product categories in 2023. It highlights individual contributions, product-wise revenue generation, and regional performance to help understand productivity patterns and identify top performers.
⭐ Overview

The Employee Sales Performance Dashboard is an analytical system designed to track, compare, and visualize the sales activities of employees across different regions and product categories.
It helps organizations understand individual productivity, identify top performers, and make data-driven decisions to improve overall sales efficiency.

⭐ Employee Data Module

Sales employees are listed in the dashboard along with key details such as:

Employee Name

Region

Product Sold

Units Sold

Total Sales Amount

This module helps managers quickly view each employee’s contribution to the company’s revenue.

⭐ Sales Overview Section

The dashboard summarizes all sales with:

Sale Date

Product Type

Price

Quantity Sold

Total Amount

It clearly highlights variations between low-ticket and high-ticket sales, making it easy to identify major revenue-driving items like LED TVs and Mobiles.

⭐ Employee Performance Page

This section analyzes each employee’s performance using:

⭐ Key Features

✔️ 1. Employee Performance Tracking
Monitors each employee’s total sales, units sold, and contribution to revenue.

✔️ 2. Product Analysis Module
Shows which products drive the most revenue (e.g., 4K LED TVs, Mobiles, LED TVs).

✔️ 3. Region-Based Sales Insights
Analyzes which locations—like Guntur and Vijayawada—generate the highest sales.

✔️ 4. Pricing & Quantity Patterns
Compares high-value bulk orders with everyday retail-level purchases.
